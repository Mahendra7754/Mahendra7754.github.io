# Mahendra Singh | Engineering Portfolio (v6)

Static GitHub Pages website. `index.html` is the homepage. `drone-tracking.html`, `ball-on-plate.html` and `csio-robotic-hand.html` are engineering case studies.

The ball-on-plate case study uses photos and a MATLAB plot from the [project repository](https://github.com/Mahendra7754/Ball-on-plate-control-kalman-filter), plus a locally supplied demonstration recording converted to a web-ready H.264 MP4. Its media lives in `assets/ball-on-plate/`.

## Publish updates

Publish changes from the repository root, keeping the complete `assets/` folder structure intact. The site has no build step.

If using Terminal after configuring Git authentication: stage the changed site files, commit, then push `main`.

Five local MP4 videos are included: two drone demonstrations, the ball-on-plate recording, and two silent CSIO internship recordings.

The contact link uses the public email on Mahendra’s GitHub profile. The About section pairs four selectable career milestones with context and images; its photos are optimized, metadata-free copies of the locally supplied `mahendra10.jpg` (graduation), `mahendra12.jpg` (Reliance Industries), and `mahendra13.jpg` (current portrait). The focus milestone uses a drone project photo. Demonstration videos play muted when visible, with controls available for sound and playback.

The CSIO case study is based on the locally supplied internship report, Python/Arduino programs and media. It describes model testing and hardware integration, with the reported 9,000-image acquisition result. Selected photos are optimized and metadata is removed. Both full-length recordings are converted to H.264 MP4 at 720p with audio removed for silent web playback. Media lives in `assets/csio/`.
