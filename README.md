# Mahendra Singh | Engineering Portfolio (v3)

Static GitHub Pages website. `index.html` is the homepage and `drone-tracking.html` is the unified mini-quadrotor engineering case study.

## Publish updates

On GitHub, upload the **contents** of this ZIP into the repository root, keeping the `assets/drone/` folder structure intact. GitHub web upload supports multiple files; to preserve folders, drag the `assets` folder from Finder into the repository upload interface (if browser does not preserve folder, create `assets/drone` in the repository first and upload media inside it). Replace `index.html`, `drone-tracking.html`, `styles.css`, `script.js` and `README.md`.

If using Terminal after configuring Git authentication: `git add . && git commit -m "Update quadrotor case study" && git push`.

Two local MP4 videos are included, so the ZIP is about 13 MB. No build step or dependencies.

**Before publishing:** replace `YOUR_EMAIL@example.com` in `index.html` with your contact email, or remove that link. Check that any photographed equipment and software is appropriate for public sharing.
