# Mahendra Singh — Engineering Portfolio

A responsive static portfolio site built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or from this folder run:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000

## Included
- Homepage: about, projects, experience, skills, contact
- Project filtering
- Detailed Indoor Drone Tracking case study
- Fly Crazy Fly continuation roadmap
- Responsive mobile navigation

## Before publishing
1. Replace the placeholder email in `index.html`. GitHub and LinkedIn profile links are already set.
2. Add actual project photographs, demo videos, technical plots and repository URLs.
3. Verify the final degree title and any CV wording.
4. Add remaining project case studies.
5. Check rights/confidentiality before sharing employer-related documents or images.

The homepage artwork is conceptual, not a photograph of the actual system.
No backend, analytics or tracking is included.
