# Mahendra Singh | Engineering Portfolio (v3)

Static GitHub Pages website. `index.html` is the homepage. `drone-tracking.html` and `ball-on-plate.html` are engineering case studies.

The ball-on-plate case study uses photos and a MATLAB plot from the [project repository](https://github.com/Mahendra7754/Ball-on-plate-control-kalman-filter), plus a locally supplied demonstration recording converted to a web-ready H.264 MP4. Its media lives in `assets/ball-on-plate/`.

## Publish updates

Publish changes from the repository root, keeping the `assets/drone/` and `assets/ball-on-plate/` folder structures intact. The site has no build step.

If using Terminal after configuring Git authentication: stage the changed site files, commit, then push `main`.

Three local MP4 videos are included: two drone demonstrations and the ball-on-plate recording.

**Before publishing:** replace `YOUR_EMAIL@example.com` in `index.html` with your contact email, or remove that link. Check that any photographed equipment and software is appropriate for public sharing.
